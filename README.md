# aku-pemula 🚀

Selamat datang di repo **aku-pemula**, tempat di mana para *coder* pemula belajar JavaScript dari nol sampai jago!

## 📌 Aturan Belajar di Repo Ini:
1. Belajar dasar-dasar JavaScript seperti variabel, fungsi, dan looping dengan santai.
2. Dilarang panik kalau kode kamu *error*, karena *error* adalah bagian dari proses.
